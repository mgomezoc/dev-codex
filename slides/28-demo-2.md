# Demo 2: auditoria rapida de un repo

Prompt:

```text
Haz una auditoria tecnica de este repo.
No modifiques archivos.

Entrega:
1. Que hace el sistema
2. Stack detectado
3. Estructura principal
4. Riesgos tecnicos
5. Riesgos de seguridad
6. Deuda tecnica
7. Plan priorizado

Usa rutas reales y explica como verificaste cada punto.
```

Esperado:
- Hallazgos ordenados por riesgo.
- Accionables inmediatos y de medio plazo.
- Riesgos con impacto y esfuerzo.

**Plan B:** si la IA no puede auditar con confianza, pedirle "reduce el alcance a 5 puntos criticos."
