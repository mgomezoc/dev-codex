# Agentes: dividir el trabajo por rol

Un agente funciona mejor con:

- Objetivo propio
- Reglas propias
- Herramientas permitidas
- Contexto especializado

**En vez de pedirlo todo a una sola respuesta:**

Arquitecto -> planea  
Desarrollador -> implementa  
QA -> prueba  
Auditor -> revisa riesgos

No uses agentes para tareas simples: primero prueba un prompt directo bien armado.
