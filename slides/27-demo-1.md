# Demo 1: construir AGENTS.md y CLAUDE.md

Objetivo:

1) Tomar un proyecto real.
2) Pedir analisis inicial.
3) Crear reglas iniciales de proyecto.
4) Revisar antes de aplicar.

Prompt base:

```text
Haz una propuesta de AGENTS.md y CLAUDE.md para este proyecto.
No modifiques archivos aun.

Entrega:
- objetivo del proyecto en una frase
- reglas obligatorias (seguridad, estilo, pruebas)
- limites de permisos sugeridos
- comandos de validacion iniciales
```

Esperado:

- Dos archivos de propuesta claros.
- Lista de riesgos puntuales.
- Lista de "no hacer" antes de guardar.

**Plan B:** si falla, mostrar el diff generado en pantalla y explicar criterios.
