# Primeros pasos recomendados

1. Crear `AGENTS.md` o `CLAUDE.md` en tu proyecto
2. Pedir una auditoria sin modificar archivos
3. Guardar prompts util para reutilizar
4. Usar ramas separadas
5. Revisar cada diff
6. Bloquear archivos sensibles
7. Convertir tareas repetidas en skills

Empieza con un proyecto no critico.
